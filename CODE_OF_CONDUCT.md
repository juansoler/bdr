# Código de conducta

Este proyecto sigue el Contributor Covenant, versión 2.1
(https://www.contributor-covenant.org/version/2.1/code_of_conduct/).

En resumen: tratemos a todas las personas con respeto, demos crítica técnica
al código y no a las personas, y seamos cuidadosos con un proyecto cuya
materia es delicada (copias de seguridad y datos de producción).

Casos: escribe a la dirección de contacto del perfil del repositorio.
Resolución: los mantenedores pueden moderar comentarios, prs y issues, y
retirar contribuciones que incumplan este código.
